 Mobile Phone Price Range Analysis – Excel Project

*Project Overview

This project focuses on analysing mobile phone specifications and understanding how different features influence mobile phone price categories.

The analysis was performed using Microsoft Excel, including data preparation, Pivot Tables, data summarisation, and dashboard visualisation.

The main objective is to explore smartphone features and classify mobile phones into different price ranges.

* Project Objectives

- Analyse mobile phone specifications.
- Understand the relationship between phone features and price ranges.
- Compare mobile phones based on RAM, battery power, screen size, and other specifications.
- Identify patterns in different price categories.
- Create an interactive Excel dashboard for better understanding of the data.

* Project Workflow

1. Data Collection: Imported the mobile phone dataset into Excel.
2. Data Preparation: Organised the dataset and checked data quality.
3. Data Cleaning: Checked for missing values and duplicate records.
4. Data Analysis: Analysed different mobile phone specifications.
5. Pivot Tables: Summarised the data based on price categories.
6. Dashboard Creation: Used visualisations to present the analysis.

*Key Findings

- The dataset contains 2,000 mobile phone records.
- All four price categories have an equal number of records.
- RAM, battery power, camera specifications, and screen features provide useful information for comparing mobile phones.
- The Pivot Table analysis helps summarise the distribution of mobile phones across price categories.
